RESTful Prediction API Endpoint

Integrate predictions seamlessly into electronic health record (EHR) systems or mobile health apps using our serialized endpoint.

POST Request (`/api/predict`)
curl -X POST http://127.0.0.1:5000/api/predict \
  -H "Content-Type: application/json" \
  -d '{
    "age": 55, "sex": 1, "cp": 2, "trestbps": 130,
    "chol": 230, "fbs": 0, "restecg": 1, "thalach": 150,
    "exang": 0, "oldpeak": 1.0, "slope": 2, "ca": 0, "thal": 2
  }'
